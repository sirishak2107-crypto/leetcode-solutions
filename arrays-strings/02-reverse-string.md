## Problem: Reverse a String (Easy)

**Link:** [LeetCode Reverse String]

### Approach

I used the two-pointer technique. One pointer starts at the beginning of the string and another starts at the end, and their characters are swapped while moving toward the center.

### Complexity

- Time: O(n)
- Space: O(1)

### Notes

A single-character string does not need any swapping.
