## Problem: Valid Anagram (Easy)

**Link:** [LeetCode Valid Anagram]

### Approach

I used a frequency-count array to count how many times each character occurs in both strings. If every character has the same frequency in both strings, the strings are anagrams.

### Complexity

- Time: O(n)
- Space: O(1)

### Notes

The strings must contain the same characters with the same frequencies.
